# Урок 14 — React Router

Многостраничное приложение на Vite + React с навигацией между разделами.

## Клонирование для проверки

```bash
git clone -b Lesson_14 https://github.com/Sergei0319/training_2026.git
cd training_2026
npm install
npm run dev
```

Откройте в браузере адрес, который выведет Vite (обычно http://localhost:5173/).

## Функционал

- Маршруты: главная (`/`), «О нас» (`/about`), «Контакты» (`/contacts`)
- Компоненты страниц: `Home`, `About`, `Contacts`
- Навигация через `react-router-dom` (`BrowserRouter`, `Routes`, `Route`, `NavLink`)
- Оформление меню и подсветка активной страницы
