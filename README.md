# Личный кабинет техподдержки ОкиДоки

SPA для специалистов поддержки: вход по SMS, запуск операций к `api.doki.online` / `api.okidoki.ru`, журнал ответов и локальное редактирование набора запросов.

## Стек

- React 19 + TypeScript + Vite
- React Router (`react-router-dom`) — маршруты по разделам
- Sass/SCSS для стилей компонентов, CSS Modules на странице «Операции» (`OperationsPage.module.scss`)
- Cloudflare Worker — прокси API и раздача SPA

Redux не используется: состояние кабинета собрано в `DeskProvider` (Context) и хуки `useAuth`, `useMethods`, `useFields`, `useRunner`, `useSettings`.

## Разделы

| Путь | Назначение |
| --- | --- |
| `/login` | Вход по телефону и SMS-коду |
| `/` | Главная: плитки быстрого запуска, журнал и ответ API |
| `/operations` | CRUD сущности **операция** (`SavedMethod`): таблица, поиск, фильтры HTTP/хост, сортировка колонок |
| `/settings` | Ключ партнёра и редактор операций |

Меню в шапке: Главная / Операции / Настройки. Журнал запросов остаётся на главной. Неавторизованный пользователь перенаправляется на `/login`.

## Архитектура

```
src/
  App.tsx                 маршруты
  desk/                   Context: сессия, операции, поля, запуск, настройки
  auth/                   SMS-сессия, клиент API, пути
  forms/                  валидация логина и редактора операции
  methods/                модель SavedMethod, шаблоны, запуск запроса
  components/             страницы и UI по папкам Component/Component.tsx + .scss
worker/                   прокси /doki-proxy и /okidoki-proxy
```

Сущность экзамена — **операция поддержки** (`SavedMethod`): создание, просмотр в таблице, изменение в редакторе, удаление. Хранение — `localStorage` браузера. Сессия (Bearer) — только `sessionStorage`, без токенов в исходниках.

Запросы к API идут через Vite-прокси в dev и через Worker на проде. Тело и query могут содержать плейсхолдеры `{{phoneNumber}}`, `{{bearerToken}}` и др.

## Валидация

- Логин: формат телефона (`+79001234567`) и SMS-код (4–6 цифр) проверяются **до** отправки на сервер; ошибки показываются под полями.
- Редактор операции: сообщения вида «Поле X неверно» для названия, пути, HTTP, хоста, JSON-тела и query.
- Плитки запуска: ошибки телефона, email, ИНН, ObjectId и обязательных полей выводятся текстом на карточке, не только в `title` кнопки.

## Запуск

```bash
npm install
npm run dev
```

Сборка и локальный Worker:

```bash
npm run preview
```

Деплой на Cloudflare:

```bash
npm run deploy
```

Вход доступен только номерам из whitelist на стороне API (`purpose: support_admin_auth`).
