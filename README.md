# work2 — React UserCard Demo

Демонстрация ререндера React-компонента при изменении props.

## Запуск

```bash
npm install
npm run dev
```

## Функционал

- Компонент `UserCard` отображает имя, возраст и цвет карточки через props
- Кнопка «Изменить возраст» увеличивает возраст
- Кнопка «Изменить цвет карточки» меняет цвет фона
- В консоли браузера логируется `Ререндер UserCard` при каждом ререндере
